# Winter Olympics Management System

A PHP web application for managing Winter Olympics event operations using MySQL and MongoDB.

## Features

- User-facing web interface
- Admin ticket management interface
- MySQL integration for relational data
- Stored procedure execution through PHP forms
- Trigger-based validation for database operations
- MongoDB-based support ticket system
- Ticket creation, comments, active/resolved status management

## Technologies Used

- PHP
- MySQL
- MongoDB
- XAMPP
- HTML/CSS
